# Weatherly

A responsive weather app built with JavaScript, Node.js, and Express. Search for a city anywhere in the world to see current conditions, a five-day forecast, sunrise and sunset, and the chance of rain. Switch between Celsius and Fahrenheit or try a popular-city shortcut.

Weather and geocoding data are provided by the free [Open-Meteo API](https://open-meteo.com/); no API key is required.

## Run locally

1. Install [Node.js](https://nodejs.org/).
2. Install the dependencies:

   ```bash
   npm install
   ```

3. Start the app:

   ```bash
   npm start
   ```

4. Open [http://localhost:3000](http://localhost:3000).

Set the `PORT` environment variable to use a port other than `3000`.
